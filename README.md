Laragon atay XAMMP
VSCode
PHP (Laragon sudah menyertakan PHP) (versi 8.2+)
MySQL / MariaDB 
Git atau bisa download via zip 

Cara install : 
1. Download file dari git beserta persyaratan tadi seperti laragon atau Xammp
2. Jika sudah copy seluruh isi dari yang sudah anda download ke folder laragon atau xammp 
(Laragon : laragon/www/)
(XAMMP : xammp/htdocs/)
3.jika sudah buka phpmyadmin dari laragon atau xammp
4.buat database baru sesuaikan namanya dengan file yang diberikan lalu import database tersebut
5.Copy Vendor.rar ke direktori aplikasi
6.jika sudah run aplikasi nya dengan CLI dengan command "php yii serve"
